# Data availability statement

All data and code supporting the findings of this study are available as follows.

## This repository

Genome collections, phylogenetic marker sets, concatenated alignments, phylogenetic trees, decontamination assessment tables, removed-contig summaries, taxonomic count tables, and ESP inventories are deposited in this repository:

**https://github.com/linweiliarchaea/Asgard-Eukaryote-Phylogenomics-2026**

(Update the URL if the repository is transferred to an institutional account.)

Key contents:

- Final genome lists for GS-Zhang2025, GS-Liu2021, GS-Present-B and their balanced (-B) and decontaminated (clean) derivatives (`data/genome_sets/`)
- Four phylogenetic marker sets and composition/overlap table (`data/PMS/`)
- Supermatrix alignments (`data/alignments/`)
- Maximum-likelihood, PMSF, CAT-GTR and AU-test outputs (`data/trees/`)
- Contamination assessment and primary decontamination summaries (`data/decontamination/`)
- ESP detection counts before and after decontamination (`data/ESP/`)
- Example analysis and figure-reproduction scripts (`scripts/`)

## External sequence data

Public genomes and MAGs were retrieved from NCBI RefSeq/GenBank and from the additional sources detailed in the genome-list tables. Accession numbers are provided in data/genome_sets/.

## Source data for figures

Summary statistics underlying main figures are included in `data/decontamination/assessment/`, `data/ESP/`, and tree files under `data/trees/`. Panel-level production notes are given in `scripts/figure_reproduction/README.md`.
